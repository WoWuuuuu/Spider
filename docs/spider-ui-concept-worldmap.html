🧭 本草稿落实的 4 点要求

  • 首层真实世界地图：等距投影（lon/lat → x/y）绘制七大洲轮廓 + 主要岛屿，不是抽象色块。
  • 按 IP 定位：入站连接按 IP 经纬度落在地图对应位置，发光点 + 外圈，hover 显详情。
  • 苹果风玻璃拟态：规则卡用 backdrop-filter: blur + 细高光边 + 斜向反射，磨砂玻璃浮在地图上。
  • 文字在玻璃外 / 电线穿玻璃：规则名与命中数标在卡片上方外侧；电线画在玻璃之上，在接入点留一颗「火花」，像从玻璃内部穿出的线。

💡 其余设计建议 可采纳

  • 玻璃要「可读」优先：blur 别超 16px，底色 8–12%，靠 1px 高光边勾轮廓，比堆透明度干净。
  • 电线即状态：活跃=实线带流光；DIRECT/BLOCK=虚线；超时=暗灰。颜色跟规则走，别另起一套。
  • 地图可降级：省电模式关掉流光与岛屿细节，只留大陆轮廓 + 点 + 线（≈ v6「省电模式」）。
  • 第三层怎么摆：地图只放「入站→规则」两层；点规则卡再右侧浮出「出站节点」玻璃卡，避免一屏三层过挤。
  • 投影选择：等距投影实现最简，但高纬（俄/加）会被拉伸；若要更准可换 Mercator（需裁剪 >85°）或 Natural Earth 折衷。
  • 点与线的遮挡：IP 密集区（美西/新加坡）点会叠在一起 —— 建议按缩放级别做聚合（>N 条合成一个带数字的簇）。
  • 无障碍：补一行文字摘要「18 条连接 → 4 条规则」，色盲用户靠形状（实/虚/点）区分。
